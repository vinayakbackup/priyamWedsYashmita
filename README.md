# Royal Wedding Invitation

- Run: `bun install && bun run dev` (build: `bun run build`).
- Edit every name, date, venue and link in `src/config.ts`.
- Drop transparent PNGs (couple, arch, scroll, tassel) into `public/assets/`; missing files show ornamental placeholders.
- Printable card lives at `/print` (A5 portrait, use the Download / Print button).
